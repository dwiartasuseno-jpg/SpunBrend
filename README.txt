SPUNBRAND WEBSITE
=================

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder spunbrand_website.
3. Klik dua kali index.html untuk melihat website di browser.

FILE
- index.html : struktur dan konten website
- style.css  : tampilan, warna, dan responsive layout
- script.js  : menu mobile, filter produk, dan tombol pemesanan WhatsApp
- assets/    : dua foto produk yang diberikan

CATATAN
- Tombol pesan membuka WhatsApp ke 081316705180 dengan pesan otomatis.
- Harga ditampilkan mulai Rp1.500/pcs sesuai informasi yang diberikan. Harga akhir perlu dikonfirmasi berdasarkan spesifikasi dan jumlah pesanan.
- Alamat dan akun media sosial ditampilkan sesuai informasi yang diberikan.
- Website ini adalah front-end katalog/e-commerce sederhana; belum terhubung ke database, pembayaran otomatis, atau sistem stok.
